# HotelHub frontend test plan

## Scope

This plan covers the static HTML, CSS, and JavaScript frontend in `frontend/`. The inspected frontend uses sample data and browser `localStorage`; it does not call the Spring Boot API for the flows below. Backend API tests are outside this report.

Run the automated tests with the static site served at `http://127.0.0.1:5500`:

```bash
npm run cy:run
```

The current Cypress suite is `cypress/e2e/hotelhub.cy.js`. Cypress can automate the listed browser interactions unless otherwise noted. “Not automated” cases are retained as manual coverage proposals and are not included in the current run.
